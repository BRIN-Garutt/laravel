# Deteksi Suhu & Kelembapan

Project Membuat Aplikasi Pendeteksi Suhu dan Kelembapan dengan menggunakan framework Laravel

#### **Perintah untuk menjalankan Front-End pada Terminal :**

```shell
$ npm run dev
```

#### **Perintah untuk menjalankan Back-End pada Terminal :**

```shell
$ php artisan serve
```
